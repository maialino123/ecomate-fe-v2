## 2. Complete Calculation Formula Flow

```
┌─────────────────────────────────────────────────────────────────────────┐
│ MATHEMATICAL CALCULATION FLOW                                          │
└─────────────────────────────────────────────────────────────────────────┘

INPUT PARAMETERS
├─ P_nhập = 5.2 CNY
├─ P_shipTQ = 10 CNY
├─ P_shipVN = 75,000 VND
├─ P_xử_lý = 50,000 VND
├─ M_fixed = 500,000 VND
├─ T_CNY→VND = 3,600
├─ SL = 50
├─ R = 0.05 (5%)
├─ F = 0.20 (20%)
├─ M_rate = 0.10 (10%)
└─ G = 0.15 (15%)

           │
           ▼

STEP 1: Total CNY Cost
┌──────────────────────────────────────┐
│ totalCNYCost = P_nhập + P_shipTQ     │
│              = 5.2 + 10              │
│              = 15.2 CNY              │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 2: Convert to VND
┌──────────────────────────────────────┐
│ totalCNYInVND = totalCNYCost ×       │
│                 T_CNY→VND            │
│               = 15.2 × 3,600         │
│               = 54,720 VND           │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 3: Total VND Cost (with marketing)
┌──────────────────────────────────────┐
│ totalVNDCost = totalCNYInVND +       │
│                P_shipVN +             │
│                P_xử_lý +              │
│                M_fixed                │
│              = 54,720 + 75,000 +     │
│                50,000 + 500,000      │
│              = 679,720 VND           │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 4: Base Cost per Unit (C₀)
┌──────────────────────────────────────┐
│ baseCost = totalVNDCost / SL         │
│          = 679,720 / 50              │
│          = 13,594.4 VND              │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 5: Effective Cost (C_eff)
┌──────────────────────────────────────┐
│ Check: R < 1? ✓ (0.05 < 1)          │
│                                      │
│ effectiveCost = baseCost / (1 - R)   │
│               = 13,594.4 / 0.95      │
│               = 14,309.9 VND         │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 6: Total Fee Rate
┌──────────────────────────────────────┐
│ totalFeeRate = F + M_rate            │
│              = 0.20 + 0.10           │
│              = 0.30 (30%)            │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 7: Suggested Selling Price (P)
┌──────────────────────────────────────┐
│ P = [C_eff × (1 + G)] /              │
│     (1 - totalFeeRate)               │
│                                      │
│ = [14,309.9 × 1.15] / 0.70           │
│ = 16,456.4 / 0.70                    │
│ = 23,509.1 VND                       │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 8: Net Profit (L)
┌──────────────────────────────────────┐
│ L = P × (1 - totalFeeRate) - C_eff   │
│ = 23,509.1 × 0.70 - 14,309.9         │
│ = 16,456.4 - 14,309.9                │
│ = 2,146.5 VND                        │
└──────────────┬───────────────────────┘
               │
               ▼

STEP 9: Break-even Price (P_BE)
┌──────────────────────────────────────┐
│ P_BE = C_eff / (1 - totalFeeRate)    │
│      = 14,309.9 / 0.70               │
│      = 20,442.7 VND                  │
└──────────────┬───────────────────────┘
               │
               ▼

FINAL RESULTS
┌──────────────────────────────────────┐
│ ✅ Calculation Complete               │
│                                      │
│ • C₀ = 13,594 VND                   │
│ • C_eff = 14,310 VND                │
│ • P = 23,509 VND                     │
│ • L = 2,147 VND                      │
│ • P_BE = 20,443 VND                  │
│                                      │
│ Profit Margin: 15.00%                │
└──────────────────────────────────────┘
```
